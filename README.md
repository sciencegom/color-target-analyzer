# 색상 타겟 영역·개체 분석기

사진에서 사용자가 지정한 **타겟 색상**, **배경 색상**, **제외 색상**을 구분하여 타겟 영역의 비율과 분리된 개체 수를 계산하는 교육용 웹 애플리케이션입니다.

- 실행 파일: `color_target_analyzer.html`
- 제작: LJB · DGHS (Daejeon Goejeong High School)
- 실행 환경: Chrome 또는 Microsoft Edge 권장
- 처리 방식: 별도 서버 없이 사용자의 브라우저 내부에서만 이미지 처리

## 이 앱에 적합한 사진

다음 조건을 만족할수록 정확하고 반복 가능한 결과를 얻기 쉽습니다.

- 분석 대상과 배경의 색상 차이가 명확한 사진
- 사진 전체에 조명이 균일하게 비친 사진
- 강한 반사광이나 짙은 그림자가 없는 사진
- 같은 실험끼리 배경, 조명, 촬영 거리와 카메라 설정이 동일한 사진
- 분석 대상이 서로 어느 정도 분리되어 있는 사진
- 글씨, 눈금, 테두리 등 불필요한 요소가 적은 사진

예시:

- 균일한 배경 위의 식물 잎이나 종자
- 색상 차이가 뚜렷한 콜로니 또는 입자
- 특정 색으로 염색된 현미경 사진
- 변색된 영역과 정상 영역의 구분
- 발색 반응이 나타난 실험지 또는 시료

## 촬영 조건이 중요한 이유

이 앱은 사진에 기록된 색과 밝기를 이용하여 대상을 구분합니다. 실제 대상의 색이 같더라도 한쪽에서 빛이 강하게 들어오면 밝은 부분과 어두운 부분이 서로 다른 색상처럼 기록될 수 있습니다.

특정 방향에서만 빛이 들어오면 다음 문제가 생길 수 있습니다.

- 같은 대상의 밝은 부분과 어두운 부분이 서로 다른 클래스로 분류됨
- 그림자가 타겟 또는 제외 영역으로 잘못 검출됨
- 반사광이 미분류 영역으로 남음
- 사진 위치에 따라 면적 비율과 개체 수가 달라짐

앱에는 완만한 밝기 차이를 줄이는 `조명·밝기 불균일 보정` 기능이 있지만, 촬영 단계에서 생긴 강한 반사와 그림자를 완전히 복원할 수는 없습니다. 가능한 한 촬영할 때부터 조명을 균일하게 만드는 것이 중요합니다.

## 권장 촬영 방법

1. 창문이나 스탠드 한쪽에서만 빛이 들어오지 않도록 합니다.
2. 가능하면 좌우 또는 여러 방향에서 확산된 빛을 사용합니다.
3. 흰 종이, 반투명 플라스틱 또는 확산판을 이용해 직접광을 부드럽게 만듭니다.
4. 카메라와 시료가 최대한 수직이 되도록 촬영합니다.
5. 플래시 사용 여부를 모든 사진에서 동일하게 유지합니다.
6. 자동 필터, 인물 모드, 색상 보정 효과는 사용하지 않는 것을 권장합니다.
7. 같은 실험군은 같은 카메라, 거리, 배경과 조명 조건으로 촬영합니다.
8. 가능하면 사진에는 분석할 시료 하나만 포함합니다.

## 분석 클래스

### 카운팅 대상

실제로 면적과 개체 수를 계산할 색상입니다.

예: 콜로니, 염색된 세포, 잎의 병반, 특정 색상의 입자

### 배경

분석 영역에는 포함되지만 타겟으로 계산하지 않는 부분입니다. 배경은 타겟 면적 비율 계산의 분모에 포함됩니다.

### 제외

분석 영역 안에 있지만 계산에서 완전히 제거할 부분입니다.

예: 글씨, 눈금, 디스크, 반사광, 접시 테두리

제외 영역은 타겟 면적 비율 계산의 분모에서도 제거됩니다.

### 미분류

등록된 색상 중 어느 쪽에도 충분히 가깝지 않은 부분입니다. 모든 픽셀을 억지로 타겟이나 배경으로 지정하지 않기 위한 안전 장치입니다.

## 기본 사용 방법

### 1. 사진 불러오기

`사진 선택 또는 촬영`을 눌러 JPG, PNG 또는 WEBP 사진을 불러옵니다.

### 2. 분석 영역 지정

`원·타원` 또는 `다각형` 도구로 실제 계산에 사용할 영역을 그립니다.

- 영역 내부를 드래그하면 전체 위치가 이동합니다.
- 조절점을 드래그하면 크기나 꼭짓점을 수정할 수 있습니다.
- 마우스 휠로 확대·축소할 수 있습니다.
- `화면 이동`을 선택하면 확대된 사진을 드래그할 수 있습니다.
- 조정이 끝나면 반드시 `영역 확정`을 누릅니다.

### 3. 분석 목적 선택

- `영역 비율`: 타겟 픽셀이 유효 분석 영역에서 차지하는 비율 계산
- `개체 카운팅`: 서로 연결된 타겟 영역을 각각 하나의 개체로 계산

### 4. 색상 표본 등록

타겟, 배경 또는 제외 카드를 선택한 뒤 다음 도구를 사용합니다.

- `점 스포이드`: 대표 색상을 한 점씩 등록
- `학습 붓`: 색상과 밝기가 조금씩 다른 넓은 영역을 칠하여 등록
- `표본 지우개`: 잘못 등록한 학습 위치 삭제

한 위치만 선택하기보다 밝고 어두운 여러 위치에서 대표 표본을 등록하는 것이 좋습니다.

학습을 마치면 `학습 완료·표시 숨김`을 눌러 분류 결과를 확인합니다. 학습 표시만 숨겨지며 등록된 색상 정보는 유지됩니다.

### 5. 판정 범위 조절

- 범위를 좁히면 선택 색상과 매우 비슷한 부분만 분류됩니다.
- 범위를 넓히면 다양한 색을 포함하지만 배경이 섞일 수 있습니다.
- 미분류 영역이 많으면 표본을 추가하거나 판정 범위를 조금 넓힙니다.
- 잘못된 영역이 많이 포함되면 범위를 좁히거나 배경·제외 표본을 추가합니다.

### 6. 카운팅 조절

개체 카운팅 모드에서는 다음 항목을 조절합니다.

- 최소 개체 크기: 작은 잡음이나 먼지를 개체 수에서 제외
- 카운팅 노이즈 정리: 고립된 픽셀을 줄이고 작은 틈을 정리

높은 노이즈 정리 단계에서는 작은 실제 개체도 사라질 수 있으므로 1단계부터 확인하는 것을 권장합니다.

## 면적 비율 계산

```text
유효 분석 면적 = 지정한 분석 영역 - 제외 영역

타겟 영역 비율(%) =
타겟 픽셀 수 ÷ 유효 분석 면적 × 100
```

미분류 비율이 크면 결과를 확정하기 전에 색상 표본과 판정 범위를 다시 확인해야 합니다.

## 개체 수 해석

개체 수는 타겟으로 분류된 픽셀 중 서로 연결된 영역을 기준으로 계산합니다.

다음 경우 실제 개체 수와 다를 수 있습니다.

- 여러 개체가 붙어 있어 하나로 연결된 경우
- 한 개체 내부의 색상 차이 때문에 여러 조각으로 분리된 경우
- 그림자, 글씨 또는 반사광이 타겟으로 분류된 경우
- 실제 개체가 최소 크기보다 작은 경우

따라서 개체 번호 화면에서 노란색 경계 하나가 실제 개체 하나에 대응하는지 반드시 확인해야 합니다.

## 결과를 비교할 때의 원칙

서로 다른 사진의 결과를 비교하려면 다음 조건을 통일해야 합니다.

- 촬영 장비
- 조명 방향과 밝기
- 카메라와 시료 사이 거리
- 배경색
- 이미지 해상도
- 분석 영역 설정 기준
- 색상 표본 등록 기준
- 판정 범위와 카운팅 설정

조건이 다른 사진의 면적 비율이나 개체 수를 직접 비교하면 촬영 차이가 실험 결과처럼 나타날 수 있습니다.

## 개인정보와 이미지 처리

불러온 이미지는 외부 분석 서버로 전송하지 않습니다. 이미지 분석은 현재 웹 브라우저 내부에서 수행됩니다.

단, 앱 자체를 웹에 배포할 때 배포 폴더에 예시 사진을 함께 넣으면 해당 사진은 공개될 수 있으므로 배포 파일에는 필요한 HTML만 포함하는 것을 권장합니다.

## 현재 버전의 한계

- 색상과 밝기 차이가 거의 없는 대상은 정확히 분리하기 어려움
- 강한 반사광과 그림자를 완전히 보정할 수 없음
- 서로 붙은 개체를 자동으로 완벽하게 분리하지 못함
- 사진의 의미나 물체 종류를 AI로 인식하지 않음
- 분석 결과는 장비 규격 판정이나 의료 진단용 결과가 아님

이 앱은 사용자가 표본을 등록하고 결과를 확인·조정하는 **교육용 반자동 분석 도구**입니다.

## 실행 방법

1. `color_target_analyzer.html`을 Chrome 또는 Microsoft Edge로 엽니다.
2. 별도 프로그램이나 서버 설치는 필요하지 않습니다.
3. 수정된 파일이 이미 열려 있다면 브라우저를 새로고침합니다.
